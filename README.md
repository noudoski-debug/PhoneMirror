# PhoneMirror

Экран iPhone на ПК + управление клавиатурой и мышью. Игра работает на самом айфоне, ПК показывает картинку и превращает клавиши в касания. Связь по USB-кабелю.

```
iPhone (TrollStore)                         Windows ПК
┌───────────────────────┐   USB / usbmuxd   ┌──────────────────────────┐
│ Broadcast-расширение  │◄─────────────────►│ PhoneMirror.exe          │
│  ReplayKit → H.264    │   TCP порт 8765   │  декодер → окно          │
│  приём касаний → HID  │                   │  клавиши/мышь → касания  │
└───────────────────────┘                   └──────────────────────────┘
```

## Установка

**На ПК**
1. Установи iTunes или приложение Apple Devices (нужен для драйвера и usbmuxd).
2. Скачай `PhoneMirror.exe` из артефактов GitHub Actions (`Build Windows app`) или запусти из исходников: `pip install -r pc/requirements.txt` и `python pc/run.py`.

**На iPhone**
1. Скачай `PhoneMirror.ipa` из артефактов `Build iOS IPA (TrollStore)`.
2. Открой файл в TrollStore и нажми Install.

## Использование
1. Подключи iPhone кабелем, нажми «Доверять».
2. Запусти `PhoneMirror.exe`.
3. На айфоне открой приложение PhoneMirror, нажми кнопку трансляции, выбери PhoneMirror Broadcast, Start Broadcast.
4. Открой игру. Картинка появится в окне на ПК.

Остановить: красная плашка в строке состояния, Stop Broadcast.

## Управление

| Клавиша | Действие |
|---|---|
| F1 | режим редактирования раскладки |
| F2 | (в режиме редактирования) поставить стик WASD: клик по центру стика |
| F3 | показать/скрыть оверлей привязок |
| F5 | сохранить профиль |
| F6 | повернуть картинку на 90° (если ориентация неверная; координаты поворачиваются вместе) |
| F7 | запросить новый ключевой кадр (если картинка «поплыла») |

Привязать кнопку: F1, клик в нужное место экрана, нажми клавишу. Удалить: правый клик рядом с привязкой. Левая кнопка мыши вне режима редактирования работает как палец (тап, перетаскивание). Профили лежат в `~/.phonemirror/profiles/*.json`, выбор: `PhoneMirror.exe --profile mygame`.

## Протокол

Сообщение: `[type u8][length u32 LE][payload]`.

| type | направление | payload |
|---|---|---|
| 0x01 HELLO | iPhone → ПК | u16 версия |
| 0x02 VIDEO | iPhone → ПК | u8 ориентация (CGImagePropertyOrientation), u8 флаги (бит0 = ключевой кадр), H.264 Annex B |
| 0x10 TOUCH | ПК → iPhone | u8 действие (0 down, 1 move, 2 up), u8 палец, f32 x, f32 y (0..1, портрет, начало слева сверху) |
| 0x11 KEYFRAME_REQ | ПК → iPhone | пусто |

## Что проверено, а что нет

Проверено на этой машине (`cd pc && python -m unittest discover -s tests`, 20 тестов):
протокол, клиент usbmuxd (против эмулятора демона), поворот и пересчёт координат, логика привязок (кнопки, стик, мышь, сброс), профили и их валидация, цикл соединения (стрим, ошибки, переподключение).

**Не проверено, так как нет Xcode, iPhone и Windows:**
- сборка Swift/Obj-C кода (CI на macOS покажет ошибки компиляции в `xcodebuild.log`);
- окно pygame и декодирование через PyAV;
- **инъекция касаний** (`ios/Broadcast/HIDBridge.m`): использует приватный IOHIDEvent API. Имена функций, поля и entitlements взяты по памяти и могут отличаться на твоей версии iOS;
- работа расширения в TrollStore (лимит памяти ~50 МБ, права ядра, нужные entitlements);
- соответствие ориентации кадра нужному повороту: если картинка повёрнута неправильно, жми F6.

Если касания не проходят, а видео идёт, дело в `HIDBridge.m` или entitlements. Если видео нет, смотри статус в окне ПК: он говорит, на каком шаге остановка.
